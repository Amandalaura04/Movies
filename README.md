# Movie Box Office Database Management

Course project examining film review patterns, disagreement and worldwide box-office revenue using PostgreSQL and Python.

## Research questions
- SQ1: Mean critic and viewer scores, review counts and variation per film.
- SQ2: Within- and between-group disagreement, and a controversy measure.
- SQ3: Reception classification, threshold sensitivity and viewer polarity.
- SQ4: Associations between review patterns and worldwide box-office revenue.

## Project workflow
1. Prepare source data locally (source datasets are not redistributed here).
2. Create PostgreSQL tables and load locally obtained data.
3. Run SQ1, SQ2, SQ3 and SQ4 scripts in dependency order.
4. Use the Python encapsulator to retrieve analysis-ready DataFrames.
5. Verify row counts, relationships and export results.

## Public repository policy
This public repository is for code and documentation only. It intentionally omits raw datasets, private student AI logbooks, credentials and student numbers. Original data access is subject to course instructions and source permissions. This repository does not claim that every query or notebook has been independently executed end to end.
