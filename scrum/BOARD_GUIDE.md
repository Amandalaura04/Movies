# Scrum evidence guide

GitHub Issues #1–#12 document the present work allocation and outstanding verification for Amanda, Jonas and Nethmi. This is a retrospective inventory of previous work, **not** evidence of historical sprint events.

Suggested GitHub Project columns: **To do**, **In progress**, **Done**. Add each issue to a project board and change its status only when supported by completed work.
